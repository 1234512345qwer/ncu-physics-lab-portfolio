## 仓库简介

本仓库是**全学期 16 周实验**的个人作品集主仓库，用途有三：

1. 存放每周实验的**原始数据、图表与实验报告**；

## 快速上手（每次实验只做 4 步）

1. **放资料**：数据放进 `weeks/weekXX/data/`，图表放进 `weeks/weekXX/figures/`；
2. **写报告**：打开 `weeks/weekXX/README.md` 按模板填写；
3. **收改动**：在终端输入 `git add .`（把改动放进「待拍区」）；
4. **拍快照**：输入 `git commit -m "完成第X周实验"` 存档，再 `git push` 上传到 GitHub。

## 小词典（常见术语大白话）

| 术语 | 大白话 |
| --- | --- |
| **仓库（Repository）** | 一个装项目的「云文件夹」，还自带时光机 |
| **Commit（提交）** | 给项目拍一张「存档快照」，以后能回到这一帧 |
| **.gitignore** | 一张「免检名单」，名单上的文件 Git 装作没看见 |
| **Push（推送）** | 把本地的存档快照上传到 GitHub 云端 |
| **README.md** | 仓库的「门面说明书」，别人点进来第一眼看到它 |
